# python-stone-paper-scissor-project-
short project stone paper scossors
The Stone Paper Scissors game is a simple and fun project developed using Python. It is a digital version of the classic hand game played between two players. In this project, the user plays against the computer. The computer makes random choices, and the winner is decided based on the traditional rules of the game:

Stone beats Scissors

Scissors beats Paper

Paper beats Stone

The project uses Python’s random module to generate the computer's move and takes the user input to compare and decide the winner. The main goal of this project is to understand basic Python programming concepts like conditionals, loops, and user input handling.
